개인정보처리방침

Calender Seyeon · 시행일 2026-09-30

1. 적용 대상

이 방침은 개인용 도구 Calender Seyeon(이하 "앱")에 적용됩니다. 앱은 소유자 한 명만 사용하며, 다른 사용자의 데이터를 수집하지 않습니다.

2. 접근하는 데이터

  • Google Calendar — 일정 조회·생성·수정·삭제
  • Google Tasks — 할 일 조회·생성·수정·완료 처리

3. 이용 목적

소유자 본인의 일정·할 일 관리를 보조하는 목적으로만 사용합니다. 광고, 프로파일링, 판매 목적으로 사용하지 않습니다.

4. 처리 및 보관

  • 인증 토큰은 소유자의 개인 PC에만 저장되며, 소유자 전용 권한으로 보호됩니다.
  • 일정·할 일 데이터를 별도 서버나 데이터베이스에 보관하지 않습니다.
  • 소유자의 요청을 처리하기 위해, 조회한 일정·할 일 내용이 AI 서비스(Anthropic Claude)로 전송되어 처리될 수 있습니다.

5. 제3자 제공

위 4항의 AI 처리를 제외하고, 데이터를 제3자에게 제공·판매·공유하지 않습니다.

6. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

7. 권한 철회

언제든지 Google 계정 → 타사 액세스에서 앱의 접근 권한을 철회할 수 있습니다.

8. 문의

이 페이지가 게시된 GitHub 저장소의 Issues를 통해 문의할 수 있습니다.

English Summary

Calender Seyeon is a single-user personal tool. It accesses the owner's Google Calendar and Google Tasks only to help the owner manage their own schedule. Tokens are stored only on the owner's PC. No data is stored on servers or sold. To fulfil the owner's requests, retrieved content may be processed by an AI service (Anthropic Claude). Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
